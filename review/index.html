StoryParts: Android export demonstration

This recording shows the actual local video export workflow on an Android 16 emulator, using a synthetic sample video and an ad-free test entitlement.

  1. The user starts the export with “Only create parts”.
  2. StoryParts displays export progress and a Cancel control.
  3. The user leaves the app. An ongoing Android notification shows that export continues in the foreground service.
  4. The user returns to the app and the completed video part is ready to share.

The service performs local media transcoding and splitting. It uses FOREGROUND_SERVICE_MEDIA_PROCESSING on Android 15 and later, and FOREGROUND_SERVICE_DATA_SYNC on earlier supported Android versions. It stops when export finishes, fails, or the user cancels. No video is uploaded.
